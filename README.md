# 🌎 Climate Change in Afghanistan — Awareness & Data Website  

This project is a **web-based platform** dedicated to raising awareness about **climate change in Afghanistan**.  
It highlights the country’s environmental challenges, presents data visualizations, and educates visitors on how climate change is impacting Afghan communities, agriculture, and natural resources.  

The website combines **data analysis**, **visual storytelling**, and **educational content** to make complex climate data accessible to the public.

---

## 🌟 Features  
- 📊 **Data Visualizations:** Interactive charts showing temperature trends, rainfall patterns, and drought severity in Afghanistan  
- 🌱 **Educational Content:** Articles explaining the causes and effects of climate change  
- 🗺️ **Regional Focus:** Insights into how different Afghan provinces are affected  
- 💡 **Call to Action:** Suggestions for community and global action toward sustainability  

---

## 🧠 Built With  
- **HTML / CSS** — for styling and content layout  
- **Plotly / Matplotlib** — for interactive data visualization  
- **Pandas** — for data cleaning and analysis
